# 合集管理

## 识别层级

- 进入「内容管理 → 稿件管理 → 合集管理」，也可打开 [合集管理](https://member.bilibili.com/platform/upload-manager/ep)。先核对合集名称、ID、状态及是否使用小节。普通合集的「查看全部」会直接打开「编辑合集」，等待视频数与行数据加载。
- 合集基本信息包含封面、标题、简介、空间防刷屏与分组开关。已见合集封面至少 960 × 540，标题 50 字符、简介 500 字符。启用分组时先显示小节表，在目标小节点「编辑、添加单集」查看内部单集。已见小节标题上限 8；若只有一个小节有稿件，页面提示播放页会隐藏小节结构。
- 每行的「单集标题」是合集内名称，「稿件标题」对应原视频。行内「编辑」打开本集标题与数字序号，已见本集标题上限 80；「编辑稿件」打开原视频。小节内还有「移动」入口，属于变更稿件归属。新增、移除、移动和改名分别依据用户授权。
- 「添加视频」或「添加单集」先打开选择窗口，可按标题或稿件 ID 搜索。结果可能包含现有成员。只有需要添加且身份核对无误时才勾选，并检查实际加入的合集或小节。
- 后台列表的创建时间、修改时间和自定义排序只用于查看列表。列表顶部「管理合集排序」管理个人空间里不同合集的展示顺序。小节排序和单集排序分别在各自表格内操作。展开下拉时优先点原触发器收起，避免弹层遮挡其他控件。

## 单集按新旧排列

普通合集的数字序号排序与提交已实测。分组合集只在用户指定的范围内操作；如果请求没说清楚是各小节内部排序，还是重新安排小节或跨小节移动，先盘点再请用户明确范围。

1. 在合集或小节编辑页记录当前顺序、各行 BV 号和成员总数。标题可能改过，或与单集标题不同，用 BV 号作为匹配依据。
2. 「最新到最老」默认按视频管理的投稿时间。用户指定按发布时间时，用可核实的实际发布时间，统一时间口径。可用共同标题前缀（如【转载】）搜索，必要时翻页或按单篇查漏。筛选结果可能包含合集以外的稿件。只排序合集已有成员，相同时间保留原有相对顺序，除非用户指定其他规则。成员身份或时间仍有缺漏时，暂不提交并报告缺口。
3. 先得出完整目标顺序。用行内「编辑」把目标第 1 集设为 1，之后按目标顺序把还未就位的行放到对应序号。已验证把一集移到较前的位置会使后续行顺延。每次点单集窗口「完成」后等待父表重排，再读序号或 BV 顺序。只改排序字段。
4. 确认目标表的成员、数量和顺序全部吻合，在对应父表点「立即提交」。等待站内反馈，再重开同一个合集或小节核对完整顺序和成员。若页面处于审核或反馈不明确，报告实际状态。
