# 视频稿件

## 进入与核对

- 已有稿件从「内容管理 → 稿件管理 → 视频管理」进入，也可打开 [视频管理](https://member.bilibili.com/platform/upload-manager/article)。搜索标题并用 BV 号核对；注意进行中、已发布、未通过和草稿的差别。点目标行「编辑」，等待原有标题、视频和设置加载。
- 新稿走「投稿 → 视频投稿」。先核对素材路径、分 P 顺序、封面、文案、创作声明、分区和用户授权的发布终点。按浏览器工具的上传指引选择文件，观察页面上传状态。格式、大小、时长及账号权限以当前界面为准。已查看上传入口，但首次上传、保存草稿与完整发布流程未在此前实验中验证。只要求草稿时，核实可用的草稿入口与保存结果；已失效草稿可能只剩部分字段。
- 已有稿件的编辑表单底部可能写「立即投稿」。在已定时稿件上，此按钮已实测用于提交定时变更。提交后仍须检查「定时发布」及时间。只读查看或只做草稿时，不能借这个按钮保存。

## 字段和权限

| 字段 | 查阅与编辑要点 |
| --- | --- |
| 封面 | 点现有缩略图打开封面制作。核对首页推荐 4:3 和个人空间 16:9 两种预览，检查主体与文字的裁切。智能封面生成失败仅反映生成状态。 |
| 标题、简介、标签 | 已见标题上限 80、简介 2000、标签 10 个。标签输入后按 Enter 创建，区分已选标签、推荐标签和活动话题。 |
| 创作声明 | 已见「内容为自制：未经作者允许，禁止转载」「内容为转载」「内容无需标注」。已有样例的选择器被锁定，能否调整须看当前稿件。转载另有来源字段，已见上限 200。标题中的【转载】、声明及来源分别核对。 |
| 分区、合集 | 可打开候选列表查现值；已有合集可能显示「清除」和「此稿件不生成更新推送」，可用性视状态而定。 |
| 视频、分 P | 核对每一 P 的名称与上传状态。添加分 P 和更换视频是独立操作。换源可能使原字幕失效；只改文案或时间时应保留视频源。 |
| 更多设置 | 已见水印、可见范围、联合投稿、卡片、章节、字幕、杜比、Hi-Res、全景、粉丝动态和空间投稿隐藏。部分开关依稿件状态锁定，检查当前值与禁用提示。 |

字幕窗口已见 SRT 和语言下拉，部分稿件只有「修改」，部分「上传字幕」禁用。章节窗口可能有预览、时间轴和分 P 选择器。界面未加载时如实说明；不能凭空白判断没有章节。只读查看用取消或关闭退出。

## 调整已有定时时间

1. 在列表确认对象仍是定时稿件，进入该条编辑，核对原有日期、时间和时区。用用户指定时区解析目标日期，跨日时确认换算后的年月日。北京为 UTC+08:00。稿件列表和数据中心曾显示不同时间，编辑页时区字段是本次设置的核对依据。
2. 检查目标时刻仍可选。已见页面提示距当前最早 5 分钟、最晚 15 天，时间面板的分钟以 5 分钟为一档。花火、预约、互动视频等可能不可改或不可取消。目标时间不可用时说明页面限制，避免自行改成相近时段或切成即时发布。
3. 保持定时开启，在日期和小时、分钟面板选择目标值。关闭面板后再次核对标题、日期、时分和时区。已授权的变更用「立即投稿」提交，观察结果，再回视频管理核对目标行仍显示「定时发布」和新时间。如果状态不明确，重开同一稿件确认，避免重复提交。

## 其他内容入口

「图文管理」区分图文、文集、草稿及专栏、动态、小站帖子。个别内容的编辑入口会提示前往「空间 → 收藏 → 我的笔记本」。根据当前提示定位编辑位置。查询表现时，可在稿件数据或数据中心查看播放、封标点击率和观看进度等可用指标。对比前统一时间口径。
