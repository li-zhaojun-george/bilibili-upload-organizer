# 投稿文案与历史标题风格

以下是可参考的标题写法。先按内容选最合适的一种，再结合自己的历史标题、目标系列和本次要求。无需每条都加前缀或使用同一种句式。

| 内容类型 | 参考写法 |
| --- | --- |
| 游戏实况、剪辑 | `【游戏名】＋具体场面＋反差／提问／口语感叹`。可用第一人称，让读者先看出发生了什么。 |
| 攻略 | `【游戏名】＋实际问题或收益＋场景／对象`，如队伍、关卡、资源收益或新手注意事项。 |
| 日常、直播录播 | `【游戏名】＋固定系列主题或当天亮点＋日期`。录播可加 `YYYY/MM/DD-段号`，沿用同系列日期写法和实际分段，避免按上传先后改段号。 |
| 剧情汇总、游戏原声 | 剧情用游戏、赛季或剧情名加进度，确已完结再标【已完结】。原声用游戏名、`游戏原声`和曲目或场景。 |
| VLOG | `【VLOG】＋物品或事件＋个人体验`，型号有辨识价值时附上。 |
| 转载 | `【转载】＋准确的中文主题`，可附英文原标题，或把游戏名放在末尾。译写时保留名称和事实。 |
| 个人连续系列 | 沿用原系列的空格、命名和版本号，例如「实 况 日 记 4.0」。 |

简介围绕实际内容写，标签优先选游戏、角色、内容形式和具体主题。转载按实际来源填写创作声明与独立的来源字段，简介可补充原作者、原标题和原链接。核实来源与用户提供的转载许可信息，避免把标题、合集名或注明出处视为授权证据。按请求给文案草稿或写入表单。

沿用系列辨识度和自然口语，避免复制历史错字或擅自统一旧稿命名。仅有标题和后台表现时，避免把播放、点击变化归因于某种标题写法。
